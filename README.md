# Images — Au Crible

Ce dépôt ne sert qu'à héberger les visuels de la newsletter
[Au Crible](https://github.com/vBuilderOnGit/au-crible), pour que les clients
de messagerie puissent les afficher.

Un mail ne sait pas afficher une image stockée sur un disque local : il lui faut
une adresse `https://` publique. GitHub Pages sert ce dépôt à cette adresse :

```
https://vbuilderongit.github.io/au-crible-images/news-<N>/<fichier>
```

Un dossier par numéro. Les originaux et le travail éditorial restent dans le
dépôt principal, qui est privé.
